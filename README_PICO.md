# Rogue 5.4 for Raspberry Pi Pico

このプロジェクトは、不朽の名作ローグライクゲーム **Rogue 5.4.4** を **Raspberry Pi Pico (RP2040)** へ移植したものです。

画面出力およびキーボード入力は、Picoの **USBシリアルポート（CDC）** を使用して行います。
パソコンとPicoをUSBケーブル1本で接続し、シリアルターミナル（115200 8N1）から直接ゲームをプレイできます。

---

## 特長

- **完全なPicoネイティブ動作**: `pico-sdk` (v2.x) を使用し、ベアメタル（No OS）で高速動作します。
- **軽量 ANSI/VT100 curses エミュレーション**:
  - ncurses に依存せず、ANSI エスケープシーケンスを用いた超軽量・高速な差分描画レイヤーを内蔵。
  - 115200bps のシリアル通信でも画面のチラつきがなく、スムーズに描画されます。
- **直感的なキーボード操作**:
  - viキー（`h`, `j`, `k`, `l`, `y`, `u`, `b`, `n`）やテンキー移動に加え、PCキーボードの **矢印キー（↑, ↓, ←, →）** や **Home/End/PgUp/PgDn** での移動に対応。
  - **Shift + 矢印キー** によるダッシュ・自動走行に対応。
- **省メモリ設計**:
  - RAM使用量: 約 61 KB / 264 KB（利用率 約23%）
  - Flash使用量: 約 235 KB / 2 MB（利用率 約11.5%）
- **リスタート機能**:
  - ゲームオーバー（死亡）時や終了時に、スペースキーを押すことで Pico のウォッチドッグリセットにより瞬時に新規ゲームを開始できます。

---

## 必要な環境・機材

1. **Raspberry Pi Pico** (または Pico W / RP2040 互換ボード)
2. **Micro USB ケーブル** (データ通信対応)
3. 開発PC環境:
   - `arm-none-eabi-gcc`
   - `cmake` (3.13 以上)
   - `pico-sdk`

---

## ビルド手順

```bash
cd /Users/toyowata/dev/pico-rogue

# ビルド用ディレクトリの作成
mkdir -p build
cd build

# CMake の実行 (PICO_SDK_PATH を指定)
cmake .. -DPICO_SDK_PATH=/Users/toyowata/pico/pico-sdk

# ビルドの実行
make -j
```

ビルドが完了すると、`build/` ディレクトリ内に以下のファイルが生成されます：
- `pico_rogue.uf2` : Pico 書き込み用ファームウェア
- `pico_rogue.elf` : ELF バイナリ
- `pico_rogue.bin` : RAW バイナリ

---

## Pico への書き込み方法

1. Raspberry Pi Pico の **BOOTSEL ボタンを押しながら**、PC の USB ポートに接続します。
2. PC に `RPI-RP2` という名前のマスストレージドライブが認識されます。
3. `build/pico_rogue.uf2` ファイルを `RPI-RP2` ドライブへドラッグ＆ドロップ（またはコピー）します。
4. コピーが完了すると自動的に再起動し、ゲームが立ち上がります。

## シリアルターミナルでの接続・プレイ方法

通信設定: **115200 bps, 8 data bits, no parity, 1 stop bit (115200, 8, N, 1)**
ターミナル推奨画面サイズ: **80 桁 × 24 行**

### macOS / Linux の場合

`tio`, `picocom`, `minicom`, `screen` などを使用できます。
ゲームオーバー後の再スタートでは Pico が再起動して USB シリアルが一度切断されるため、
自動で再接続してくれる **`tio` を推奨** します。

```bash
# デバイス名の確認 (/dev/tty.usbmodem* など)
ls /dev/tty.usbmodem*

# tio で接続する場合 (推奨。Pico 再起動後も自動で再接続されます / 終了は Ctrl-T -> Q)
brew install tio        # macOS の場合
tio -b 115200 /dev/tty.usbmodemXXXX

# picocom で接続する場合
picocom -b 115200 /dev/tty.usbmodemXXXX

# または screen で接続する場合 (終了は Ctrl-A -> K)
screen /dev/tty.usbmodemXXXX 115200
```

> **注意: 再スタート後に端末の表示が崩れる場合**
>
> `screen` などは、接続中のデバイスが突然消えると（Pico の再起動による USB 切断）、
> 端末設定を元に戻さずに終了することがあります。その結果、`ls` などの出力が
> 階段状にずれて表示されます（改行時に行頭へ戻らない）。
> その場合は以下のどちらかを入力して Enter を押すと元に戻ります
> （表示が崩れていても入力は受け付けられます）。
>
> ```bash
> stty sane
> # または
> reset
> ```
>
> 再接続するには、Pico の再起動後にもう一度 `screen` などを起動してください。

### Windows の場合

- **Tera Term** / **PuTTY** / **VS Code Serial Monitor** などを起動
- ポート: Pico の COM ポート
- ボーレート: `115200`
- 端末タイプ: `VT100` または `xterm`

### 接続後の操作

1. シリアルポート接続後、`Rogue 5.4 - Raspberry Pi Pico 日本語移植版` のウェルカム画面が表示されます。
   - Pico は USB シリアル（CDC）にホストが接続されるまで起動待ちになります。UART のみでの起動には対応していません。
   - 端末の文字コードは **UTF-8** に設定してください。
2. **スペースキー** または **Enterキー** を押すとダンジョン生成が始まり、ゲームがスタートします。

## ゲームの基本操作

| キー | 動作 |
|---|---|
| `↑` `↓` `←` `→` または `k` `j` `h` `l` | 上下左右に移動 / 攻撃 |
| `Home` `PgUp` `End` `PgDn` または `y` `u` `b` `n` | 斜め移動 |
| `Shift + 矢印キー` または `K` `J` `H` `L` | 障害物や壁に突き当たるまで走る |
| `s` | 周囲を探索（隠し扉・罠の発見） |
| `.` または `Space` | 1ターン休む |
| `i` | 持ち物一覧（インベントリ） |
| `e` | 食料を食べる |
| `q` | ポーションを飲む |
| `r` | 巻物を読む |
| `w` | 武器を装備する |
| `W` | 鎧を着る |
| `T` | 鎧を脱ぐ |
| `P` | 指輪をはめる |
| `R` | 指輪を外す |
| `z` | 杖を振る |
| `t` | アイテムを投げる |
| `d` | アイテムを置く（捨てる） |
| `>` | 階段を降りる |
| `<` | 階段を登る |
| `?` | キーヘルプを表示 |
| `Q` | ゲームを終了してスコア画面へ |

---

## 制限事項

- 名前入力（アイテムへの命名など）は ASCII 文字のみ対応です。日本語の入力はできません。
- 持ち物一覧の表示方式（オプション `inventory`）の `Overwrite` には対応していません。選択しても `Clear` として動作します。
- ファイルシステムが無いため、ゲームのセーブ（`S` コマンド）はできません。スコアも保存されません。
